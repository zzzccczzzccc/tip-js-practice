 Описание выполненных работ

 Практическая работа № 1: Базовый синтаксис JavaScript
    Цель:   Изучение базовых типов данных, функций, циклов и отладки кода.
    Выполненные задания:   
  - Написаны скрипты для работы с переменными и типами данных (`types.js`).
  - Реализована приветственная функция (`hello.js`).
  - Составлен учебный план с использованием массивов и циклов (`plan.js`).
  - Написана функция расчета прогресса выполнения задач (`progress.js`).
    Результаты проверки:   Все скрипты успешно выполняются, вывод данных в консоль браузера корректен, синтаксических ошибок нет.

 Практическая работа № 2: Объекты, массивы и сервисный слой
    Цель:   Проектирование структур данных и написание бизнес-логики (сервисов) для управления задачами.
    Выполненные задания:  
  - Создан набор начальных данных (`data.js`) с массивом объектов задач.
  - Реализован сервисный модуль (`task-service.js`), содержащий функции получения, добавления, удаления и изменения статуса задач с использованием современных методов массивов (`map`, `filter`).
    Результаты проверки:   Функции сервиса корректно обрабатывают структуры данных, обеспечивая чистую изоляцию бизнес-логики.

 Практическая работа № 3: DOM-дерево, селекторы и интерактивный интерфейс
    Цель:   Связывание логики приложения с пользовательским интерфейсом (DOM) и обработка событий.
    Выполненные задания:  
  - Разработана HTML-разметка и CSS-стили интерфейса управления задачами.
  - Написаны модули селекторов (`task-selectors.js`) и отрисовки интерфейса (`task-view.js`).
  - Реализован главный скрипт взаимодействия (`main.js`), обрабатывающий отправку формы добавления задачи, клики по кнопкам удаления и изменения статуса выполнения, а также обновление счетчиков сводки.
